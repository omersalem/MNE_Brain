      Operations & Safety Policy

      MNE_Brain Release 2 core safety architecture rules and operational boundaries.

      Read-Only Discovery Default

      Telemetry discovery and exact registered P7 checks run only after separate activation under the authenticated owner session; live reads are disabled at rest. Read access never inherits write permissions.

      Zero Credential Exposure

      Passwords, SSH private keys, API secrets, and raw authentication tokens are filtered out server-side. No credential material ever reaches the browser or model context.

      Controlled Write Execution

      Every write operation requires an exact server-prepared preview, risk rating, verification procedure, and single-use owner approval. Unseen changes are permanently blocked.

      Loopback Bound

      The MNE_Brain server binds strictly to loopback (127.0.0.1). Sessions are authenticated via HttpOnly cookies and protected with CSRF nonces.
