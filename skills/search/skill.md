# Skill: Search (`skills/search/skill.md`)

> **Inheritance:** Extends `[[AGENTS.md]]` and `[[base-agent.md]]`.

## 1. Purpose
Search the Brain for infrastructure objects. If an object is unverified or missing, uses the Observation-Interpretation Framework to state observed facts vs. unknown parameters.

## 2. Layered Workflow
1. **Search Layer 1 `knowledge/` & Layer 3 `intelligence/`:** Locate matching notes and Wiki links (`[[Entity-Basename]]`).
2. **Formulate Observation Matrix:** List observed vault facts, hypotheses for missing fields, and required verification.
3. **Execute Read-Only Verification:** Conclude with standard Verification Summary block. Mask all credentials.
